# Metadata Strategy

## Overview

Metadata digunakan untuk:
- search ranking
- CTR optimization
- social sharing
- semantic SEO

---

# Metadata Philosophy

Semua dynamic page wajib memiliki:
- unique title
- unique description
- optimized OG tags
