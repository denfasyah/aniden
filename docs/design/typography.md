# Color System

## Overview

Aynime menggunakan color palette cyberpunk modern dengan pendekatan:
- dark cinematic
- neon futuristic
- elegant contrast
- immersive streaming atmosphere

---

# Theme Modes

## Dark Mode
Theme utama Aynime.

Fokus:
- cinematic experience
- neon contrast
- immersive streaming

---

## Light Mode
Theme sekunder.

Fokus:
- clean readability
- soft futuristic look
- minimal brightness fatigue

# Gradient Rules

Gradient digunakan untuk:
- hero overlay
- premium section
- CTA emphasis

Jangan gunakan gradient berlebihan.

---

# Glow Rules

Glow hanya digunakan pada:
- active element
- premium badge
- CTA hover
- focused content

Glow harus subtle dan modern.
