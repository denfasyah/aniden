# Naming Convention

## Overview

Naming convention wajib konsisten untuk:
- readability
- maintainability
- scalable collaboration
- AI-agent understanding

---

# General Principles

Gunakan:
- descriptive naming
- concise naming
- predictable naming

Hindari:
- singkatan tidak jelas
- nama ambigu
- nama terlalu panjang

---

Gunakan:
```txt id="x8q4vn"

```

Contoh:
```txt id="z2m7xp"

```
