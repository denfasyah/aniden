# Aynime Documentation

## Overview

Aynime is a modern anime streaming web platform built with a cyberpunk-inspired design system and modern web technologies.

The platform focuses on:

- fast anime discovery
- modern streaming experience
- personalized user experience
- scalable architecture
- AI-assisted features
- premium subscription system

This documentation serves as:

- project blueprint
- architecture reference
- development guideline
- AI-agent context source

---

Project Goals

Main Goals

- Build a modern anime streaming platform
- Create scalable architecture from the beginning
- Provide clean and responsive UI/UX
- Support guest, user, and premium flows
- Optimize for SEO and performance
- Prepare future AI-powered features

---

Tech Stack

Frontend

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

Backend / Infrastructure

- Supabase
- Prisma ORM
- Auth.js
- Midtrans

APIs

- Wajik Anime API
- Otakudesu API

Development Workflow

Recommended workflow:

1. Read related docs
2. Understand feature scope
3. Read task file
4. Implement feature
5. Review result
6. Update docs if necessary

---

AI Agent Workflow

When using AI agents:

- provide focused context only
- reference related docs
- work task-by-task
- avoid large multi-feature prompts

Recommended pattern:

- Read architecture docs
- Read feature docs
- Read related task
- Implement isolated feature
